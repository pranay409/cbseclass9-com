Polynomials for CBSE Class 9: Factor Theorem and Identities Explained

Published on October 29, 2026

Polynomials form the backbone of algebra in CBSE Class 9 Maths (Chapter 2, NCERT). Understanding polynomials, the factor theorem, and algebraic identities is crucial for scoring well in board exams and competitive entrance tests. This comprehensive guide covers everything you need to master this essential topic.

Understanding Polynomials: NCERT Chapter 2 Fundamentals

A polynomial is an algebraic expression consisting of variables and coefficients combined using addition, subtraction, and multiplication operations. According to NCERT Class 9, polynomials are classified based on their degree and number of terms.

Key Definitions:

  • Degree of a polynomial: The highest power of the variable in the polynomial. For example, in 3x² + 2x + 5, the degree is 2.
  • Coefficient: The numerical factor of each term. In 5x³, 5 is the coefficient.
  • Constant term: The term without a variable.
  • Monomial: Polynomial with one term (e.g., 7x).
  • Binomial: Polynomial with two terms (e.g., x + 5).
  • Trinomial: Polynomial with three terms (e.g., x² + 3x + 2).

⚠️ Common Mistake to Avoid

Students often confuse polynomials with other algebraic expressions. Remember: a polynomial cannot have negative powers or fractional powers of variables. For example, x⁻¹ + 2 or √x + 3 are NOT polynomials. This distinction is frequently tested in CBSE board exams.

Polynomial Classification:

Linear Polynomial: ax + b (degree 1, e.g., 2x + 3)
Quadratic Polynomial: ax² + bx + c (degree 2, e.g., x² + 5x + 6)
Cubic Polynomial: ax³ + bx² + cx + d (degree 3, e.g., x³ + 2x + 1)

The Factor Theorem and Its Applications

The Factor Theorem is one of the most important concepts in CBSE Class 9 polynomials. It states that: "If (x - a) is a factor of polynomial p(x), then p(a) = 0. Conversely, if p(a) = 0, then (x - a) is a factor of p(x)."

Practical Application with Examples:

Example 1: Check if (x - 2) is a factor of p(x) = x³ - 2x² - x + 2.

Solution: Substitute x = 2 in p(x):
p(2) = 2³ - 2(2)² - 2 + 2 = 8 - 8 - 2 + 2 = 0
Since p(2) = 0, (x - 2) is a factor.

Step-by-Step Factorization Using Factor Theorem:

  1. Identify possible rational roots using the Rational Root Theorem (factors of constant term ÷ factors of leading coefficient).
  2. Test each candidate by substituting in the polynomial.
  3. When p(a) = 0 is found, (x - a) is a factor.
  4. Use polynomial division to find other factors.

Why Factor Theorem Matters in Exams:

  • Direct application in 2-3 mark questions on factorization
  • Essential for solving higher-degree polynomial problems
  • Foundation for understanding polynomial equations in higher classes
  • Frequently appears in CBSE board exams and entrance tests

Algebraic Identities: Essential Formulas for Class 9

NCERT Chapter 2 emphasizes six major algebraic identities that form the cornerstone of polynomial manipulation. These identities are used extensively for expanding, factorizing, and simplifying expressions.

The Six Standard Identities:

(a + b)² = a² + 2ab + b²

(a - b)² = a² - 2ab + b²

(a + b)(a - b) = a² - b²

(x + a)(x + b) = x² + (a + b)x + ab

(a + b)³ = a³ + 3a²b + 3ab² + b³

(a - b)³ = a³ - 3a²b + 3ab² - b³

Additional Important Identities:

  • a³ + b³ = (a + b)(a² - ab + b²) - Used for factorizing sum of cubes
  • a³ - b³ = (a - b)(a² + ab + b²) - Used for factorizing difference of cubes
  • a³ + b³ + c³ - 3abc = (a + b + c)(a² + b² + c² - ab - bc - ca) - Applied in complex problems

Practical Application Example:

Expand (2x + 3)²:
Using identity (a + b)² = a² + 2ab + b²
Here a = 2x, b = 3
(2x + 3)² = (2x)² + 2(2x)(3) + 3² = 4x² + 12x + 9

Factorize 9x² - 25y²:
Using identity a² - b² = (a + b)(a - b)
Here a = 3x, b = 5y
9x² - 25y² = (3x)² - (5y)² = (3x + 5y)(3x - 5y)
